# مار سه‌بعدی

یک مار سه‌بعدی در مرورگر. مار داخل یک مکعب نئونی حرکت می‌کند، گوی طلایی را می‌بلعد و اگر به دیوار یا بدنش برخورد کند دور تمام می‌شود.

صحنه با Three.js ساخته شده و صفحه را Vite سرو می‌کند. منطق بازی در `src/logic.js` از رندر جداست.

## اجرا

```bash
npm install
npm run dev
```

بعد از بالا آمدن سرور، بازی روی [http://127.0.0.1:47231](http://127.0.0.1:47231) باز می‌شود.

```bash
npm test
npm run build
npm run preview
```

## کنترل‌ها

جهت‌ها نسبت به دوربین‌اند، نه محورهای ثابت جهان. اگر دوربین را بچرخانی، «جلو» هم با نگاه تو می‌چرخد.

- جهت‌نما یا W A S D: حرکت روی سطح افق
- Q یا PageUp: بالا
- E یا PageDown: پایین
- فاصله، P یا Escape: مکث
- کشیدن ماوس: چرخاندن دوربین
- غلتک: نزدیک و دور شدن
- دوبار کلیک: برگشت دوربین به نمای پشتی

با کیبورد فارسی هم کار می‌کند، چون جایگاه فیزیکی کلید ملاک است. روی صفحه‌ی کوچک، دکمه‌های لمسی پایین صفحه همان حرکت‌ها را انجام می‌دهند.

حلقه‌ی روشن روی کف مکعب، جای افقی سر مار را نشان می‌دهد تا ارتفاعش گم نشود. امتیاز و رکورد در همین مرورگر ذخیره می‌شود.
